# FormatikLab — sito istituzionale

Sito statico bilingue (italiano/inglese) realizzato con HTML, CSS e JavaScript, pensato per GitHub Pages.

## Pubblicazione con GitHub Pages

1. Aprire le impostazioni del repository `FormatikLab/FormatikLab`.
2. Selezionare **Pages** nella barra laterale.
3. In **Build and deployment**, scegliere **Deploy from a branch**.
4. Selezionare il branch `main` e la cartella `/ (root)`, quindi salvare.
5. Attendere il completamento della pubblicazione. L'indirizzo del sito sarà mostrato nella stessa pagina.

## Modifiche

La pagina principale è `index.html`. I testi italiani e inglesi sono gestiti nell'oggetto `translations` dello script in fondo al file.
